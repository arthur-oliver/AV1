COMANDOS - GREENCODE

1. ENTRAR NA PASTA DO PROJETO
cd "...\greencode"

2. INSTALAR DEPENDÊNCIAS
npm install

3. COMPILAR O PROJETO
npm run build

4. INICIAR O SISTEMA
npm start

--------------------------------------------------
TESTES DA CLI
--------------------------------------------------

LOGIN
login --usuario admin --senha Admin@123

SAIR DA SESSÃO
logout

--------------------------------------------------
ORGANIZAÇÃO
--------------------------------------------------

CRIAR ORGANIZAÇÃO
org criar --razao "Empresa Teste" --cnpj 11222333000181 --ie 123456789 --endereco "Rua Teste, 100" --telefone 11999999999 --email teste@empresa.com --vencimento 10 --valor 500

LISTAR ORGANIZAÇÕES
org listar

--------------------------------------------------
LOTE
--------------------------------------------------

CRIAR LOTE
lote criar --org ID_DA_ORGANIZACAO --nf NF001 --transp "Transportadora Teste" --data 2026-09-22

ADICIONAR EQUIPAMENTO AO LOTE
lote add-equip --lote ID_DO_LOTE --tipo NOTEBOOK --marca Dell --modelo Latitude --peso 2 --ano 2024

FAZER TRIAGEM
lote triagem --lote ID_DO_LOTE

--------------------------------------------------
EQUIPAMENTO
--------------------------------------------------

RASTREAR EQUIPAMENTO
equip rastrear --id ID_DO_EQUIPAMENTO

ALTERAR STATUS
equip status --id ID_DO_EQUIPAMENTO --status AGUARDANDO_DESMONTE

--------------------------------------------------
RELATÓRIOS
--------------------------------------------------

RELATÓRIO POR STATUS
relatorio status --status AGUARDANDO_DESMONTE

RELATÓRIO POR ORGANIZAÇÃO
relatorio org --org ID_DA_ORGANIZACAO --inicio 2026-01-01 --fim 2026-12-31

--------------------------------------------------
ENCERRAR
--------------------------------------------------

logout
sair


OBSERVAÇÕES
- Execute os comandos depois de aparecer: greencode>
- Substitua ID_DA_ORGANIZACAO pelo ID retornado ao criar/listar a organização.
- Substitua ID_DO_LOTE pelo ID retornado ao criar o lote.
- Substitua ID_DO_EQUIPAMENTO pelo ID retornado ao adicionar o equipamento.
- Se quiser apenas testar o login, use:
  login --usuario admin --senha Admin@123
